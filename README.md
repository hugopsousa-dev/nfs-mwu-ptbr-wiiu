# Need for Speed: Most Wanted U — PT-BR para Wii U

**Download atual: v1.1 — assistente de instalação para Windows e Mac.**

- [Baixar o ZIP](https://github.com/hugopsousa-dev/nfs-mwu-ptbr-wiiu/releases/latest/download/NFS-MostWanted-U_PTBR_WiiU.zip)
- [Como instalar, passo a passo](COMO_INSTALAR.md)
- [Ler o guia no navegador](https://hugopsousa-dev.github.io/guias/NFS-MWU-PTBR.html)

Região **USA / NTSC-U** · Title ID `0005000010128800`. O pacote contém deltas e código próprio; você fornece os arquivos da sua cópia do jogo. O assistente gera a pasta `wiiu`; não copie `patches` para o SD. Aroma precisa ter SDCafiine instalado e ativado separadamente.
